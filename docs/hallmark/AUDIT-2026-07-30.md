## Ranked punch list

### P0 — Critical tells

| # | Anti-pattern | Where | Evidence | Fix direction (do not auto-apply) |
|---|--------------|-------|----------|-----------------------------------|
| 1 | **Gradient headline** (`background-clip: text`) | `src/app/page.tsx` hero | `from-violet-300 via-cyan-200 to-sky-300 bg-clip-text text-transparent` | Solid ink or single accent word weight; keep brand violet without gradient fill |
| 2 | **Purple → cyan/indigo attractor** | Home hero glow, CTAs, pricing preview, header CTA | `PublicHero` blurs; `HomeClosingCta` / `CTASection` violet gradients; header `from-violet-500 to-indigo-500` | One solid accent button; soft single-hue surface tint instead of multi-stop hero gradients |
| 3 | **3-column icon-above-heading cards** | `HomeAfterSummarySection`, `FeatureGrid` (many SEO pages), `ModeDetailSections` use-cases | Lucide icon → title → body in equal columns | Break symmetry: 2+1 layout, typography-led rows, or unequal spans; drop icon-above pattern on home |
| 4 | **AI footer (index columns)** | `PublicFooter` | 6–7 link columns: Summarizers / Segments / Resources / Intelligence / Product / Company + social | For marketing close: denser colophon or statement footer; keep sitemap on a dedicated hub if needed |
| 5 | **Re-drawn UI chrome** | `ProductMockCard` | Fake traffic-light dots + “Summify · Workspace” title bar | Prefer screenshot/`<figure>` of real workspace or chrome-less mock |

### P1 — Structural sameness

| # | Anti-pattern | Where | Fix direction |
|---|--------------|-------|---------------|
| 6 | **Hero → features → CTA rhythm** | Home + most `FormatLandingTemplate` / use-case pages | Vary section order per page type (e.g. proof/demo before feature grid on format pages) |
| 7 | **Shared FeatureGrid fingerprint** | 15+ pages import `FeatureGrid` | Page-specific layouts; reserve FeatureGrid for true comparison/feature dumps only |
| 8 | **Identical CTA blocks** | `CTASection`, `HomeClosingCta` | Differ closing pattern by page (inline link, letter close, single line) |
| 9 | **Equal whitespace section stacking** | Home after-hero sections | Alternate surface tint / hairline rule / density between sections |
| 10 | **AI nav shape** | `PublicHeader` | Wordmark · Formats · Segments · Workspace · Pricing · CTA — classic SaaS. Acceptable for hub, but consider quieter edge-aligned nav on long SEO landings |

### P2 — Craft / gates

| # | Gate / tell | Where | Fix direction |
|---|-------------|-------|---------------|
| 11 | `transition-all` | Header CTAs, `FeatureGrid`, `UseCaseSection`, mega menu | Transition only `color`, `border-color`, `opacity`, `background-color` |
| 12 | Accent footprint | Violet glow + gradient CTAs dominate first viewport | Cap accent area; neutrals carry more of the canvas |
| 13 | Card nesting / glow cards | Pricing preview highlighted tier, ProductMock panels | One containment layer; reduce nested borders |
| 14 | Hover multi-effect stacks | Feature cards border + bg + shadow together | One hover property max |
| 15 | Interactive state completeness | Many marketing buttons | Audit `:focus-visible` / disabled on shared `Button` |
| 16 | Reduced motion | Public motion/hover CSS | Ensure `prefers-reduced-motion` coverage where animations exist |

### OK / brand-aligned (do not “fix away”)

| Item | Why OK under Summify brand lock |
|------|----------------------------------|
| Geist sans | Distinctive enough; not Inter/Roboto; pairing already set |
| `#0e1016` base | Tinted dark, not pure `#000` |
| Violet `#8b5cf6` as product accent | Locked brand signal — reduce *volume*, don’t replace with Hallmark catalog theme |
| Lucide as sole icon set | Single library (passes mixed-icon gate) |
| Format-specific SEO pages | Content specificity is real; layout reuse is the issue, not the IA |
